🛠️ Ça ne marche pas ? Vérifie la configuration
  1. (Facultatif, seulement pour « Se connecter avec Discord ») Dans index.html, en haut du script : colle le Client ID de ton application Discord.
  2. Discord → OAuth2 → Redirects : ajoute exactement
  3. Firebase → Authentication → Méthode de connexion → Anonyme : activer.
  4. Firebase → Firestore Database : créer la base, puis Règles → publier firestore.rules.
  5. Ouvre le site via son adresse https://…web.app, pas en double-cliquant sur le fichier.
